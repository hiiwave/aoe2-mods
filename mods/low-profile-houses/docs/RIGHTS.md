# Rights, privacy and repository scope

This private repository contains authored transformation/codec code, hand-traced parameters, specifications, non-image manifests and curated documentation figures. It does not claim ownership of Age of Empires artwork.

Excluded:
- Original game SLD/SMX/DRS/DAT files.
- Raw generated sprites and mod ZIPs (unless a later release decision explicitly changes this boundary).
- Unrelated screenshots, private conversations and other personal material.
- Third-party mod packages or executables.
- User account identifiers, machine-specific absolute paths, credentials and raw private conversation logs.

The owner has explicitly authorized relevant project screenshots and visual comparisons in this private repository. Curated asset previews and gameplay screenshots may document the project; label them accurately and retain only necessary game content. Explanatory SVG diagrams are authored illustrations, not game artwork or gameplay evidence. This permission does not transfer ownership of game artwork or authorize public redistribution. The historical lecture PDF itself is not uploaded at the owner's request; relevant mathematics is integrated into documentation.

The exclusion is a conservative distribution boundary, not a legal opinion that every mod distribution is prohibited. The trial ZIP already delivered to the owner is separate from this source repository. Adding binary releases or making the repository public should first resolve the applicable game-content distribution terms and intended audience.

Public attribution uses hiiwave only. No software license is asserted for third-party assets. Authored code is retained for private project use; choose an explicit public license before any public source release.
